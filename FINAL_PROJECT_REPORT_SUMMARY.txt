1. EXECUTIVE OVERVIEW & PROBLEM STATEMENT
================================================================================
Traditional early-stage venture capital diligence is fundamentally flawed:
- SLOW & EXPENSIVE: Traditional due diligence takes 3 to 6 weeks per company,
  costing thousands of dollars in analyst hours.
- SUBJECTIVE & BIASED: Reliance on pitch decks and founder charisma frequently
  leads to investing in hype over engineering substance.
- THE "DECK VS. REALITY" GAP: Up to 65% of software pitch decks make claims
  about proprietary algorithms, advanced AI, or enterprise security that do
  not exist in the underlying codebase.
- UNSTRUCTURED & SILOED DATA: Pitch decks (PDFs), code repositories (GitHub),
  financial updates (Excel), and public market signals (news, competitor funding)
  exist in fragmented silos that humans struggle to cross-verify.

VENTURELENS SOLUTION:
VentureLens is an autonomous, multi-agent artificial intelligence diligence platform
that ingests pitch decks, live GitHub code repositories, and external web data to
produce institutional-grade evaluation scorecards, risk analyses, and investment
recommendations in under 5 minutes with mathematical consistency and 100% source
provenance (zero financial hallucination).

3. ANALYSIS MODES (MODE A: STARTUP VS. MODE B: PROJECT)
================================================================================
VentureLens pioneers dual-mode ingestion catering to both established startups
and open-source/developer projects transitioning to commercialization:

MODE A: STARTUP EVALUATION
- Target: Pre-Seed to Series A startups with existing pitch decks and financial decks.
- Ingestion Files: Pitch Deck (PDF/PPTX), Financial Statements (XLSX/PDF), Founder
  Updates, Company Governance Documents, Website URL, Founder Profiles.
- Processing Path: Preprocessing -> Agent 1 -> Agent-Research -> Agent 2 ->
  Agent 3 -> Agent 4 -> Agent 5 -> Investor Dashboard.

MODE B: PROJECT -> STARTUP CONVERSION
- Target: Hackathon projects, open-source repositories, developer tools looking
  for venture backing or angel investment.
- Ingestion Inputs: Public/Private GitHub Repository URL, Compiled Codebase,
  README documentation, Project Description, Demo URL, Traction metrics.
- Processing Path: Code Preprocessing (AST) -> Agent 6 -> Agent-Research ->
  Agent 2 -> Agent 3 -> Agent 4 -> Agent 5 -> Investor Dashboard.

4.1 AGENT 1: DOCUMENT ANALYSIS AGENT
--------------------------------------------------------------------------------
- Directory: Agent1/Agent_1/backend/
- Port: 8001 (FastAPI)
- Core Responsibilities:
  1. Multimodal Document Parsing: Ingests PDFs, presentations, spreadsheets,
     and textual disclosures using PyPDF, pdfplumber, and custom extractors.
  2. Structured Entity Extraction: Uses Google Gemini 2.5 Flash with strict
     Pydantic output schemas (StartupAnalysis, MergedStartupAnalysis).
  3. Key Extraction Pillars:
     - Basic Info: Canonical name, description, industry, stage.
     - Founders & Team: Executive names, roles, backgrounds.
     - Financial Claims: Self-reported ARR, MRR, Burn Rate, Runway, Margins.
     - Market Claims: Founder TAM/SAM/SOM estimates.
     - Business Model: Target customers, pricing strategy, monetization structure.
     - Competitors & Risks: Competitors claimed in the pitch deck.
     - Evidence Citations: Quotes, page numbers, and extraction confidence.
- Database Integration: Saves structured document extractions to `public.evaluations`.

4.2 AGENT 6: CODE INTELLIGENCE AGENT (PROJECT -> STARTUP)
--------------------------------------------------------------------------------
- Directory: Agent-6/backend/
- Port: 8000 (FastAPI)
- Core Responsibilities:
  1. Automated Repository Cloning & Traversal: Fetches public/private GitHub
     repositories, intelligently ignoring build artifacts, virtual environments,
     node_modules, test binaries, and cache folders.
  2. AST & Dependency Diligence: Performs static Abstract Syntax Tree (AST)
     analysis across Python, TypeScript, JavaScript, Go, and Rust.
  3. Feature Ground-Truth Classification: Categorizes claimed project features
     into three deterministic verification tiers:
     - SUPPORTED: Definite implementation found in AST and source code logic.
     - INFERRED: Indirect evidence found in package.json/requirements.txt or imports.
     - UNKNOWN / UNSUPPORTED: Claimed in README/marketing but absent in code.
  4. Technical Maturity & Quality Rating:
     - Architecture pattern extraction (Microservices, Monolith, Serverless).
     - Code quality, database connection pooling, async patterns, security flaws.
     - Files audited count, chunk creation, token management.
  5. Inter-Agent Handoff: Implements both a REST handoff API
     (`/agent6/github/handoff/latest`) and disk-based caching
     (`storage/agent6_outputs/latest.json`) consumed seamlessly by Agent 2.

4.4 AGENT 2: DATA EXTRACTION & NORMALIZATION
--------------------------------------------------------------------------------
- Directory: Agent-2/backend/
- Port: 8003 (FastAPI)
- Core Responsibilities:
  1. Field Normalization Engine (field_normalizer.py):
     - Currencies & Multipliers: Converts `$1.2M`, `₹50 Lakhs`, `€500k`, `10B`,
       `5 Cr` into pure numeric floats and standard ISO currency codes (USD/INR/EUR).
     - Percentages: Normalizes `24%`, `+15.5%`, `0.24` into standard float percentages.
     - Dates: Converts `2025-09-06`, `Sep 6, 2025`, `06/09/2025`, `Q3 2024` into ISO 8601.
     - Technology Taxonomy: Standardizes 50+ aliases (`reactjs` -> `React`,
       `postgres` -> `PostgreSQL`, `k8s` -> `Kubernetes`).
     - Startup Stage & Industry: Canonical mapping across 15+ industry sectors.
  2. Duplicate Detection Engine (duplicate_detector.py):
     - Fuzzy string similarity (SequenceMatcher) and corporate suffix stripping
       (`Inc`, `LLC`, `Corp`, `Labs`, `AI`) to merge duplicate competitor entities.
     - Deduplicates founder profiles and risk factor lists across all agents.
  3. Conflict Resolution Engine (conflict_resolver.py):
     - Source Authority Priority:
       * Technical Features: Agent 6 (Code AST) > Agent 1 (Pitch Deck).
       * Market Sizing: External Research > Agent 1 (Pitch Deck).
       * Financials: Audited Statements / Web > Forward-looking Projections.
     - Explains every resolution in structured `ConflictRecord` logs.
  4. Cross-Metric Validation Engine (data_validator.py):
     - ARR vs. Annualized MRR mismatch audit (`|ARR - MRR*12| > 20%` flagged).
     - Market sizing sanity audit (`SAM <= TAM` and `SOM <= SAM`).
     - Unit economics audit (`LTV/CAC < 1.0x` flagged as unprofitable acquisition).
     - Runway bounds audit (warns if cash runway < 3 months).
     - Missing critical fields audit with downstream impact descriptions.
  5. Source Provenance Tracker (provenance_tracker.py):
     - Zero Financial Hallucination Guarantee: Unmentioned values remain null.
     - Every normalized metric tracks originating agent, document/URL citation,
       evidence snippet, extraction timestamp, and confidence score.
  6. Output & Storage:
     - Produces `UnifiedStartupEvaluationDataset` consumed directly by Agent 3.
     - Dual-persisted to Supabase `public.normalized_startup_profiles` and local
       resilient JSON cache (`storage/normalized_outputs/latest.json`).
  7. Test Coverage: 14/14 automated pytest cases passing in 0.44s.

4.5 AGENT 3: MULTI-DIMENSIONAL SCORING ENGINE
--------------------------------------------------------------------------------
- Directory: Agent-3/backend/
- Port: 8004 (FastAPI)
- Core Responsibilities:
  1. Six-Pillar Analytical Evaluation (0 - 100 Normalized Scale):
     - Pillar 1: Market Score (TAM, SAM, SOM, CAGR, Market Tailwinds).
     - Pillar 2: Product & Tech Score (AST verified features, code maturity, tech stack).
     - Pillar 3: Team Score (Founder technical presence, domain experience, pedigree).
     - Pillar 4: Financial Score (Capital efficiency, runway, burn rate, margins).
     - Pillar 5: Traction Score (User metrics, ARR growth, pilot commitments).
     - Pillar 6: Risk Calibration Score (Contradictions, moat risks, regulatory threats).
  2. Calibration & Weighting Matrix:
     - Applies calibrated weights depending on startup stage (Pre-Seed emphasizes
       Team & Market; Series A emphasizes Financials & Traction).
  3. Distress & Anomaly Detection:
     - Detects fatal red flags (e.g., runway < 3 months, LTV/CAC < 1.0, unverified tech).
  4. Status Categorization: Categorizes startups into Exceptional, Strong,
     Moderate, or Distressed.
- Database Integration: Saves evaluation matrices to `public.startup_evaluations`.

4.6 AGENT 4: INSIGHT & RECOMMENDATION GENERATOR
--------------------------------------------------------------------------------
- Directory: Agent-4/backend/
- Port: 8005 (FastAPI)
- Core Responsibilities:
  1. Investment Thesis Synthesis:
     - Leverages Google Gemini with business rule fallbacks to craft an executive
       investment thesis detailing why an investor should or should not invest.
  2. Key Insights Generation:
     - Core Strengths: Competitive advantages, verified technical assets, moat.
     - Risks & Concerns: Valuation mismatch, unverified marketing claims, burn rate.
     - Strategic Opportunities: Expansion into adjacent sub-sectors, open-source GTM.
     - Next Steps: Recommended milestones prior to term sheet issuance.
  3. Due Diligence Questions Generator:
     - Formulates 4 to 10 pointed questions for founders across Technical,
       Financial, Go-To-Market, and Team categories.
     - Annotates each question with "Why It Matters" and "Expected Strong Answer".
  4. Final Investment Recommendation Verdict:
     - Outputs deterministic verdict: `INVEST`, `MONITOR`, `MAYBE`, or `PASS`.
- Database Integration: Persists recommendations to `public.investment_recommendations`.
