# Agent 6 → Agent 2 Integration Guide

This guide explains how **Agent 2 (Data Extraction & Normalization)** accesses and consumes the technical evaluation output generated by **Agent 6 (Project → Startup Code Agent)**.

---

## 📍 Where Agent 6 Output is Stored

Whenever Agent 6 runs (via LangGraph graph execution, FastAPI endpoint, or CLI script), its validated payload is automatically saved into:

1. **Specific Evaluation Run File**:
   `Agent-6/backend/storage/agent6_outputs/<owner>_<repo>_<timestamp>.json`
   *(e.g., `Shiv24angi_EcoVerse_20260905_202718.json`)*

2. **Repository Latest Pointer**:
   `Agent-6/backend/storage/agent6_outputs/latest_<owner>_<repo>.json`

3. **Global Latest Pointer**:
   `Agent-6/backend/storage/agent6_outputs/latest.json`

4. **Runs Registry Index**:
   `Agent-6/backend/storage/agent6_outputs/index.json`

---

## 🛠️ How Agent 2 Can Access the Output

There are **two easy ways** for Agent 2 to access Agent 6's data:

### Method 1: Direct Python Service Import (Recommended for local / monolithic pipeline)

In Agent 2's Python code:

```python
from services.agent6.storage import storage

# 1. Fetch the latest output globally
payload = storage.get_latest()

# 2. OR fetch the latest output for a specific repository
payload = storage.get_latest(owner="Shiv24angi", repo_name="EcoVerse")

# 3. OR fetch by specific run_id
payload = storage.get_by_run_id("Shiv24angi_EcoVerse_20260905_202718")

# Access the technical claims & evidence
findings = payload["findings"]
repository = payload["repository"]
metadata = payload["metadata"]

print(f"Loaded {len(findings)} findings from Agent 6 for {repository['full_name']}")
```

---

### Method 2: HTTP REST API (Recommended for microservices / decoupled agents)

When `Agent-6/backend` is running (`uvicorn app.main:app --reload --port 8000`):

| Endpoint | Method | Description |
| :--- | :--- | :--- |
| `/agent6/github/handoff/latest` | `GET` | Get most recent evaluation output |
| `/agent6/github/handoff/latest?owner=Shiv24angi&repo=EcoVerse` | `GET` | Get latest output for specific repo |
| `/agent6/github/handoff/runs` | `GET` | List all historical evaluation runs |
| `/agent6/github/handoff/{run_id}` | `GET` | Retrieve specific evaluation by run ID |

Example in Agent 2:
```python
import requests

response = requests.get("http://localhost:8000/agent6/github/handoff/latest")
if response.status_code == 200:
    data = response.json()
    print("Agent 6 findings received:", data["findings_summary"])
```
